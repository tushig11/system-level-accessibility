# System-Level Accessibility  
## Solo Developers (1–3 People)

---

## Focus

Prioritize high-impact accessibility with minimal overhead.

---

## Key Layers

- Architectural Constraint  
- Distribution  
- Enforcement (lightweight)

---

## Practices

- use semantic HTML always  
- enforce accessible naming  
- run axe DevTools in browser  
- test keyboard navigation  

---

## Avoid

- building custom UI without need  
- skipping manual checks  
- ignoring focus behavior  

---

## Outcome

Accessibility becomes a default behavior, not extra work.
