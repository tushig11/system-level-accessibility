# System-Level Accessibility  
## Startups (4–15 People)

---

## Focus

Balance speed and accessibility consistency.

---

## Key Layers

- Architectural Constraint  
- Distribution  
- Enforcement  

---

## Practices

- build shared component library  
- enforce accessibility in PR reviews  
- run CI accessibility checks  
- track accessibility issues  

---

## Avoid

- duplicating components  
- skipping accessibility reviews  
- delaying accessibility fixes  

---

## Outcome

Accessibility scales without slowing development.
